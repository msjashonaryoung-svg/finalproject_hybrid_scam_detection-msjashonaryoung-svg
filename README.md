# Hybrid Scam Detection

Comparative computational linguistics project building an explainable NLP system for cryptocurrency scam detection using symbolic rules, BERT, and hybrid modeling.

## Research Question
Which framework best detects scam language:
1. Rule-based linguistic system
2. BERT-based contextual system
3. Hybrid system

## Planned Components
- Data collection
- Text preprocessing
- Rule engine
- BERT classifier
- Hybrid scoring
- Evaluation metrics
- Final analysis
